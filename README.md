# mivelta-media

Public image hosting for Mivelta social posts (used by Metricool via raw URLs).

- `assets/` — brand assets: Velta poses, glossy symbol, gradient background, app icon, flat SVG symbol.
- `posts/YYYY-MM-DD/` — final post images (JPEG, 1080×1350).
- `scripts/` — Pillow scripts that compose post images from `assets/` (font: Poppins).

Raw URL pattern: `https://raw.githubusercontent.com/ukadirov/mivelta-media/main/<path>`
